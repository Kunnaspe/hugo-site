## About My Site

This is a Hugo static site deployed to an AWS S3 bucket; developed and delivered via AWS CodePipeline and CodeBuild.

### Technologies 

- **Hugo** - Static site generator
- **AWS S3 Bucket** - Static website hosting
- **CodePipeline** - Provides continuous delivery
- **CodeBuild** - Automation
- **GitHub** - My repo
